How It Works:
-------------
Every PHP page that includes header.php automatically gets analytics:

    <?php include 'includes/header.php'; ?>
    <!-- Your content -->
    <?php include 'includes/footer.php'; ?>

The analytics script is injected via:
    
    <script type="module">
      import { inject } from 'https://cdn.jsdelivr.net/npm/@vercel/analytics@1/dist/index.js';
      inject();
    </script>
